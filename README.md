# 🦀 Bob Esponja Action Verbs Game

A modern, interactive web application for learning English action verbs with SpongeBob SquarePants!

## 🎮 Features

- **Interactive Carousel**: Learn 7 action verbs with images and audio
- **Crossword Puzzle**: Practice spelling with a 7x7 grid
- **Termo-style Feedback**: Color-coded hints (green/yellow/gray)
- **Reward System**: Congratulatory banners with audio feedback
- **Modern Design**: Glass morphism and gradient effects

## 🚀 Live Demo

## 🎯 How to Play

1. **Learn**: Watch the carousel with SpongeBob action images
2. **Practice**: Complete the crossword puzzle
3. **Check**: Get color feedback like Wordle/Termo
4. **Celebrate**: Enjoy reward animations when you succeed!

## 🛠️ Technologies Used

- HTML5
- CSS3 (Modern gradients, glass morphism)
- JavaScript (ES6+)
- Responsive Design
